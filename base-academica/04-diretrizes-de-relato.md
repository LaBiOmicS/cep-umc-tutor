# Diretrizes de relato por desenho

As diretrizes da rede EQUATOR (<https://www.equator-network.org>) dizem **o que um estudo deve relatar** para ser
avaliado e reproduzido. Num projeto, elas servem como **lista do que planejar**. A versão atual de cada uma deve ser
conferida no site da EQUATOR, que registra as atualizações.

| Desenho | Diretriz | Para o projeto (protocolo) |
|---|---|---|
| Ensaio clínico randomizado | **CONSORT** | **SPIRIT** (itens de protocolo) |
| Estudo observacional (coorte, caso-controle, transversal) | **STROBE** | STROBE como lista de planejamento |
| Acurácia diagnóstica | **STARD** | STARD |
| Pesquisa qualitativa (entrevistas, grupos focais) | **COREQ** ou **SRQR** | COREQ / SRQR |
| Questionário ou survey | **CROSS**; **CHERRIES** para questionários online | CROSS / CHERRIES |
| Relato de caso | **CARE** | CARE |
| Revisão sistemática | **PRISMA** | **PRISMA-P** (protocolo) |
| Melhoria da qualidade em serviços de saúde | **SQUIRE** | SQUIRE |
| Modelos de predição (inclusive com IA) | **TRIPOD** / **TRIPOD+AI** | TRIPOD |
| Relato de estatística em qualquer desenho | **SAMPL** | SAMPL |
| Sexo e gênero em qualquer desenho | **SAGER** | SAGER |

**Como o tutor usa esta tabela**
- **Graduação:** apresenta a diretriz como material de estudo ("vale conhecer a STROBE; ela lista o que um estudo
  transversal precisa descrever").
- **Especialização:** recomenda seguir.
- **Mestrado em diante:** espera que o projeto siga e cite a diretriz.
