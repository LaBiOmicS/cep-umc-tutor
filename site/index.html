Duas trilhas que nunca se misturam

O que o CEP cobra, de um lado. O que melhora o trabalho, do outro.

O CEP avalia ética, não a qualidade científica, salvo quando a metodologia gera viés ético (item PROJ-G05 do modelo de projeto). Por isso o relatório tem duas partes, com rótulos diferentes, e uma sugestão acadêmica nunca aparece como se fosse exigência do comitê.

Parte 1 · Ética e documentos

Exigências do CEP-UMC, tiradas de 274 requisitos com ID estável. A base foi montada a partir dos modelos de 2022, do Regimento de 2025, do Manual da Plataforma Brasil e da Cartilha da CONEP.

  • [BLOQUEANTE], [PENDÊNCIA] ou [RECOMENDAÇÃO], com o trecho e o requisito
  • Documentos esperados × recebidos (TCLE, TALE, TAI, carta de anuência…)
  • Igual para todos os níveis: o que é exigência vale para todo mundo

Parte 2 · Sugestões acadêmicas

Metodologia, estatística e escrita, com base nas diretrizes EQUATOR, nas normas ABNT e na literatura metodológica. Não são cobradas pelo CEP: quem decide é o pesquisador, com o orientador.

  • [SUGESTÃO] dividida em Essencial e Para aprofundar
  • Calibrada pelo nível: o que se espera de um TCC não é o que se espera de uma tese
  • Erro é erro em qualquer nível; o que muda é a profundidade e o tom
Para quem

Cada perfil começa por um lugar diferente.

Aluno de graduação

Ainda não sabe que documentos precisa

O planejamento pergunta o essencial (menores? online? local de coleta?) e lista os documentos, quem assina cada um e a data-limite para submeter. Depois, o relatório abre com "Comece por aqui": até cinco ações, em ordem, e uma legenda do que é bloqueante, pendência e sugestão.

Aluno de pós

Projeto longo, prazo apertado

Lê projetos de dissertação e tese inteiros. Calcula a data para submeter a partir do início da coleta no cronograma, com margem para uma pendência. Se você incluir o PDF "Informações Básicas" da Plataforma Brasil, confere se ele bate com o projeto. A cada rodada, mostra o que já foi resolvido.

Orientador

Precisa decidir rápido se pode submeter

O relatório do orientador tem uma página: se o protocolo está pronto ou não, o que falta, quem assina cada documento e o prazo. Na graduação, lembra que é o orientador quem submete na Plataforma Brasil.

Escolha abaixo o seu sistema e a IA que vai usar. O guia mostra só os comandos certos para a sua escolha. Em cada caixa escura, clique em copiar e cole no terminal.

AutorizaçãoO texto vai para o serviço de IA. Para revisar o protocolo de outra pessoa, peça permissão antes.

  1. Abra o terminal

    O terminal é uma janela onde você digita comandos. Você vai usá-lo só para colar o que está nas caixas escuras deste guia.

    No Windows, aperte a tecla ⊞ Win, digite PowerShell e abra o programa Windows PowerShell.

    No Mac, aperte ⌘ Cmd + Espaço, digite Terminal e aperte Enter.

    No Linux, aperte Ctrl + Alt + T ou procure Terminal no menu de aplicativos.

    Para colar: clique com o botão direito dentro da janelause ⌘ Cmd + Vuse Ctrl + Shift + V. Depois aperte Enter para executar.

  2. Instale o uv

    O uv é um programa gratuito que baixa, sozinho, as peças em Python que o tutor usa para ler os documentos e gerar os relatórios em PDF.

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Ao terminar, feche o terminal e abra outro. Isso vale para todos os passos de instalação.

  3. Instale o assistente de IA

    É o assistente que vai conduzir a revisão. O instalador não mostra progresso enquanto baixa; espere a linha de comando voltar.

    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash
    irm https://antigravity.google/cli/install.ps1 | iex
    curl -fsSL https://antigravity.google/cli/install.sh | bash

    Abra um terminal novo e confira. Deve aparecer um número de versão:

    claude --version
    agy --version

  4. Entre na sua conta

    Digite o comando abaixo. Na primeira vez, o navegador abre para você entrar na sua conta; volte ao terminal quando terminar.

    claude
    agy

    Quando aparecer a pergunta sobre confiar na pasta, escolha Yes. Para sair do assistente, digite /exit.

    Para sair do assistente, aperte Ctrl + C duas vezes.

  5. Instale o tutor

    Com o Claude Code aberto (passo 4), cole as duas linhas, uma de cada vez, apertando Enter depois de cada uma:

    > /plugin marketplace add LaBiOmicS/cep-umc-tutor
    > /plugin install cep-umc-tutor@labiomics

    Depois digite /exit. O tutor passa a funcionar na próxima vez que você abrir o Claude Code. Se você já usa outro plugin LaBiOmicS, o marketplace labiomics é o mesmo.

    Baixe o plugin em cep-umc-tutor-0.2.0.zip e extraia o arquivo (clique direito → Extrair tudo no Windows; dois cliques no Mac). No terminal, fora do assistente, digite agy plugin install com um espaço no final, arraste a pasta extraída para a janela e aperte Enter. Depois ative o plugin:

    agy plugin install C:\Users\Ana\Downloads\cep-umc-tutor-0.2.0/Users/ana/Downloads/cep-umc-tutor-0.2.0/home/ana/Downloads/cep-umc-tutor-0.2.0
agy plugin enable cep-umc-tutor

  6. Separe os documentos numa pasta

    Crie uma pasta, por exemplo tcc dentro de Documentos, e dentro dela uma subpasta protocolo com os documentos que vão para a Plataforma Brasil: projeto, folha de rosto, TCLE, TALE, TAI, cartas, questionários. Use os modelos oficiais do CEP-UMC.

    No terminal, digite cd (com espaço), arraste a pasta tcc para a janela e aperte Enter:

    cd C:\Users\Ana\Documents\tcc/Users/ana/Documents/tcc/home/ana/Documentos/tcc
    Ainda sem documentos? Pule para o passo 7 e peça o planejamento: o tutor diz o que preparar.

  7. Peça a revisão

    Ainda nessa pasta, abra o assistente e escreva o pedido com as suas palavras, ou use um dos prompts prontos.

    claude
    agy
    > Revise meu protocolo da pasta protocolo/ antes de submeter ao CEP-UMC.
    O assistente vai confirmar com você o tipo de cada documento, as respostas da triagem (menores? online? material biológico?) e o nível do trabalho antes de avaliar. Confira: os documentos exigidos e o tom das sugestões dependem disso. Ele também vai pedir permissão para rodar programas (uv run …); escolha Yes.

  8. Leia o relatório e corrija

    Os arquivos ficam em cep_tutor/<projeto>. O aluno começa pelo relatorio.pdf, em "Comece por aqui". O orientador começa pelo relatorio_orientador.pdf.

    Corrija e peça a revisão de novo. A partir da segunda rodada, o tutor confere o que já apontou e mostra o que foi resolvido. São no máximo três rodadas: depois disso, conclua com o orientador e submeta.

    A IA pode errar. O relatório é um rascunho a conferir com o orientador; em caso de dúvida, consulte o CEP-UMC.

Como funciona

Programas onde dá para contar, IA onde é preciso ler.

Leitura dos documentos, triagem, sinais automáticos, severidade e montagem do relatório são programas determinísticos e testados. Os modelos de linguagem entram só para ler o protocolo e julgar, um revisor para cada parte, sem que um veja o trabalho do outro.

Ler e classificar

Extrai o texto de .docx, .doc e .pdf, identifica cada documento e acha restos de modelo (trechos em vermelho, "XXX") e texto oculto.

Triagem

Menores? Online? Material biológico? Local de coleta? Daí sai a lista de documentos esperados × recebidos e o nível do trabalho.

Revisor da Parte 1

Lê tudo com a base do CEP-UMC, confirma ou descarta cada sinal automático e cita o trecho e o ID de cada requisito.

Revisor da Parte 2

Lê o projeto e os instrumentos com a base acadêmica e o nível do trabalho. Não repete o que é da Parte 1.

Revisão com fim

Corrigir não abre uma lista nova a cada rodada.

O pior que um tutor pode fazer é o ciclo "corrige, aparece mais coisa". Por isso a revisão tem um número fixo de rodadas, e cada parte do relatório tem um limite de itens.

Rodada 1

Revisão completa. As duas partes, com tudo o que a base cobre.

Bloqueantes e pendências nunca são cortados.

Rodadas 2 e 3

Conferência. O tutor verifica o que já apontou: resolvido, ainda pendente. Item novo só entra se for bloqueante ou pendência ética; nada de sugestões novas.

Rodar de novo sem mudar os documentos não conta rodada.

Depois da 3ª

Ciclo encerrado. Só a conferência da parte ética. O relatório recomenda concluir com o orientador e submeter.

O limite pode ser mudado, mas o padrão é três.

Perguntas frequentes

Se algo não funcionar.

O terminal diz que o comando não foi encontrado.

Quase sempre basta fechar o terminal e abrir um novo. Se continuar, reinicie o computador e repita o passo de instalação.

O assistente não reconhece o tutor.

Feche o assistente e abra de novo: o plugin só é carregado numa sessão nova. Confira se ele aparece como ativado:

claude plugin list
agy plugin list
O tutor disse que eu preciso de um documento que não se aplica.

A triagem é heurística. Diga ao assistente, por exemplo, "não há menores no estudo" ou "a coleta não é online": ele refaz a lista de documentos esperados.

O nível do trabalho saiu errado.

Sem indicação na capa, o tutor assume graduação. Diga o nível ("é uma tese de doutorado") e ele refaz a revisão com a calibração certa. A Parte 1 não muda com o nível; só a Parte 2.

Já fiz três rodadas e ainda há pendências.

É de propósito: depois da terceira, o tutor só confere a parte ética. Resolva os itens restantes com o orientador e, se a dúvida for sobre uma exigência, consulte o CEP-UMC (cep@umc.br). O tutor ainda ajuda com perguntas pontuais e com a carta-resposta.

Meus documentos ficam guardados em algum lugar?

Os arquivos gerados ficam só no seu computador, em cep_tutor/. O texto dos documentos é enviado ao serviço de IA que você usa (Claude ou Antigravity), nos termos da sua conta. Protocolos podem conter dados pessoais: para revisar o protocolo de outra pessoa, peça autorização antes.

Os PDFs dos relatórios não aparecem.

Eles dependem do uv (passo 2). Confirme que uv --version mostra uma versão e peça ao assistente para compilar de novo. Os arquivos .md trazem o mesmo conteúdo.

git clone https://github.com/LaBiOmicS/cep-umc-tutor.git

S=skills/cep-tutor/scripts; OUT=cep_tutor/meu-projeto

uv run $S/cep_tutor.py run     --output-dir $OUT --runner claude
uv run $S/cep_tutor.py compile --output-dir $OUT
uv run $S/cep_tutor.py planejar --output-dir cep_tutor/plano --nivel graduacao --coleta 2027-06-01 --q "Q7=sim"
uv run $S/kb.py search "assentimento"
Uso responsável

Apoio ao pesquisador, não um parecer.

Quem decide é o CEP

O tutor aponta o que os documentos do CEP-UMC costumam cobrar. A severidade é uma classificação editorial, não um critério oficial do comitê, e nada aqui prevê aprovação.

Quem orienta é o orientador

As sugestões acadêmicas são alternativas para discutir, não correções. Escolhas metodológicas combinadas com o orientador são respeitadas.

Dados de pesquisa são sensíveis

Use o tutor com os seus próprios documentos ou com autorização. Textos ocultos e instruções dirigidas à IA dentro dos documentos são ignorados e aparecem como alerta de integridade.
