# Emendas, notificações e recursos

## 1. Emenda

**O que é:** toda proposta de modificação do projeto aprovado, enviada pela Plataforma com **descrição e justificativa**
das alterações e com os **trechos modificados destacados** nos documentos.

| ID | Regra |
|---|---|
| EMD-01 | Só em projetos **aprovados**; **uma emenda por vez** (a próxima só depois de concluída a análise da anterior). |
| EMD-02 | A emenda **não pode descaracterizar** o estudo. Mudanças substanciais no **desenho, nas hipóteses, na metodologia ou nos objetivos primários** exigem **novo protocolo**. |
| EMD-03 | Na etapa 6, redigir a **justificativa** listando os campos alterados. |
| EMD-04 | Multicêntrico ou com coparticipante: marcar se a emenda é **exclusiva do centro coordenador**. Para replicar a **todos** os centros, marcar como **não exclusiva**. Não existem emendas exclusivas de coparticipante. |
| EMD-05 | Exemplos típicos: alterar o cronograma, incluir local de coleta ou coparticipante, mudar a equipe, ajustar instrumento ou TCLE. |
| EMD-06 | Com pedido de alteração de pesquisador responsável em análise, **não é possível** submeter emenda. |

## 2. Notificação

**O que é:** envio de documentos ao CEP **sem alterar o conteúdo** do projeto (alteração de conteúdo = emenda). Só em
projetos **aprovados**.

| Tipo de notificação | Tratamento no CEP |
|---|---|
| Comunicação de início do projeto | Ciência |
| Envio de relatório de início do projeto | Ciência |
| Carta de autorização da instituição | Ciência |
| Comunicação de término do projeto | Ciência |
| **Relatório parcial** | Relatoria (gera parecer) |
| **Relatório final** | Relatoria (gera parecer) |
| **Relatório de suspensão** | Relatoria. Suspende o estudo por prazo determinado (ex.: à espera de patrocínio). |
| **Relatório de cancelamento** | Relatoria. Usado quando o estudo não pode continuar. |
| Outros | Relatoria e/ou ciência |

- O CEP-UMC **acompanha os projetos por relatórios anuais** (Regimento, art. 14 f): prever relatórios parciais (anuais)
  e o relatório final no cronograma.
- Suspender ou encerrar a pesquisa exige **autorização prévia do Sistema CEP/CONEP** (PROJ-C11).
- Notificações ao CEP coordenador **não são replicadas** aos CEPs dos centros participantes ou coparticipantes.

## 3. Recurso

| ID | Regra |
|---|---|
| REC-01 | Cabe contra parecer de **não aprovado**. **Um único** recurso ao CEP, em até **30 dias corridos** após a emissão do parecer. |
| REC-02 | Indeferido no CEP → recurso à **CONEP** (última instância), em 30 dias. |
| REC-03 | O recurso deve trazer **justificativa** e, segundo o Regimento, **fato novo** que fundamente a reanálise; documentos podem ser anexados. |
| REC-04 | Não cabe recurso para **coparticipante** não aprovada. |
| REC-05 | O sistema só oferece a opção de recurso dentro do prazo de 30 dias. |
