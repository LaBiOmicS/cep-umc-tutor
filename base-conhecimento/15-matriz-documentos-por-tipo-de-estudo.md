# Quais documentos o protocolo precisa?

## 1. Perguntas de triagem (o tutor deve fazê-las ou inferir as respostas)

| # | Pergunta | Se SIM → |
|---|---|---|
| Q1 | Os participantes são **maiores de 18 anos e capazes**? | TCLE (papel → `04`; online → `05`) |
| Q2 | Há participantes **menores de 18 anos** ou **legalmente incapazes**? | **TALE + TCLE do responsável** (`06`), com justificativa da população (TALE-02) |
| Q3 | O consentimento será obtido **online** (formulário)? | TCLE em ambiente virtual (`05`) e descrição do recrutamento online (PROJ-N08) |
| Q4 | Haverá **coleta ou uso de material biológico**? | TCLE de cessão de amostra (`07`) e **consulta prévia ao CEP** |
| Q5 | Haverá **armazenamento** de amostra para uso futuro? | **Consultar o CEP**: biobanco ou biorrepositório (Res. 441/11) |
| Q6 | A pesquisa usa **somente prontuários, laudos ou bases secundárias** e é **inviável** obter o TCLE? | **Solicitação de dispensa** (`08`) + TAI do detentor dos dados |
| Q7 | A coleta ocorre em um **local específico** (hospital, clínica, escola, empresa, ONG, serviço)? | **TAI de cada local** (`09`) |
| Q8 | O projeto ou o TCLE promete **encaminhamento a um serviço** para atender danos (clínica-escola, Policlínica UMC, psicólogo)? | **Carta de anuência para assistência gratuita** (`10`) |
| Q9 | Há **instituições coparticipantes** cadastradas na Plataforma? | **Um Termo de Anuência por coparticipante** (TAI-12) |
| Q10 | É **multicêntrico**? | Lista de centros com pesquisador e CEP de cada um (PROJ-E03); cadastro pelo centro coordenador |
| Q11 | Há **financiamento externo** ou patrocinador? | **Comprovante do apoio e dos valores** (PROJ-C12); assinatura do patrocinador na folha de rosto, se "Institucional Principal" |
| Q12 | Há **imagem, áudio ou vídeo** dos participantes? | Cláusula específica no TCLE/TALE (TCLE-C10) |
| Q13 | Há **grupo-controle**? | Cláusula de acesso ao tratamento eficaz (TCLE-C05, PROJ-B06) |
| Q14 | Testa **novo método profilático, diagnóstico ou terapêutico**, medicamento ou dispositivo? | Continuidade do tratamento / acesso pós-estudo (Res. 466, III.3.d); situação regulatória (PROJ-E01); verificar se cabe análise pela CONEP |
| Q15 | Envolve **genética humana**, **reprodução humana**, **indígenas** ou outra **área temática especial**? | Verificar a tramitação pela **CONEP** (PB-S03) e as resoluções específicas |
| Q16 | O pesquisador principal é **aluno de graduação**? | O **orientador** deve ser o pesquisador responsável; o aluno entra como assistente (PB-U03) |
| Q17 | É **relato de caso ou série de casos**? | Pode ser necessário anexar o **TCLE já assinado**: consultar o CEP (TCLE-F13) |
| Q18 | É pesquisa de **Ciências Humanas e Sociais**? | Res. 510/16; registro de consentimento em formato alternativo é possível (TCLE-F16) |
| Q19 | Há **brindes** para participantes (sobretudo crianças)? | Declarar no TALE, no TCLE e no projeto que não são remuneração (TALE-T07) |
| Q20 | Há **coleta de dados pessoais em ambiente digital**? | Medidas de proteção e menção à LGPD (TCLEV-09) |
| Q21 | Qual o **nível do trabalho** (IC/TCC de graduação, especialização/residência, mestrado, doutorado, pesquisa docente)? | Graduação: o **orientador** é o pesquisador responsável e o aluno entra como assistente (PB-U03). Também calibra a Trilha B (ver `PLANO-DO-PLUGIN.md`). |

## 3. Regra de ouro de consistência
Cada documento listado deve aparecer **(a)** anexado separadamente na Plataforma Brasil **e (b)** ao final do projeto
detalhado, **com conteúdo idêntico** (PROJ-G07, PROJ-C15). Título, pesquisador responsável, equipe, locais, amostra,
cronograma e orçamento devem ser **os mesmos** em todos os documentos e no formulário.
