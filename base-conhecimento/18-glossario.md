# Glossário

| Termo | Definição |
|---|---|
| **Anexo** | Documento **não** elaborado pelo autor do projeto (ex.: escala validada, TAI). |
| **Apêndice** | Documento elaborado pelo autor do projeto (ex.: questionário próprio, TCLE). |
| **Anonimização** | Tornar os dados não identificáveis. |
| **Assistente de pesquisa** | Pesquisador com acesso ao projeto na Plataforma (edita, submete, envia emendas e notificações; não exclui). Perfil padrão de aluno de graduação. |
| **Biobanco / biorrepositório** | Coleção organizada de material biológico humano, com regras próprias (Res. CNS 441/11). Armazenar amostras para uso futuro exige essa estrutura. |
| **CAAE** | Certificado de Apresentação de Apreciação Ética, gerado quando o CEP aceita o projeto após a checagem documental. |
| **Carta de anuência** | Declaração de uma instituição concordando com a pesquisa (coparticipante) ou com a prestação de assistência gratuita. |
| **Carta-resposta** | Documento com que o pesquisador responde, item por item, às pendências do parecer consubstanciado. |
| **CEP** | Comitê de Ética em Pesquisa: colegiado interdisciplinar e independente, consultivo, deliberativo e educativo. |
| **Cessão de amostra** | Fornecimento de material biológico em que o participante **mantém direitos** sobre ele (≠ doação). |
| **Checagem / validação documental** | Primeira etapa do CEP (até 10 dias): verificar se os documentos obrigatórios estão presentes e corretos. |
| **CHS** | Ciências Humanas e Sociais (Res. CNS 510/16). |
| **CONEP** | Comissão Nacional de Ética em Pesquisa (CNS). Última instância de recurso; analisa áreas temáticas especiais. |
| **Coparticipante** | Instituição onde ocorre alguma etapa da pesquisa, com o mesmo pesquisador responsável da proponente. |
| **Dano associado à pesquisa** | Agravo imediato ou tardio, ao indivíduo ou à coletividade, com nexo causal direto ou indireto com o estudo. |
| **Desenho do estudo** | Tipo de abordagem metodológica (população e amostra, unidade de análise, intervenção, seguimento). |
| **Desfecho primário** | Principal resultado esperado, ligado ao objetivo geral. Só pode haver um, definido antes do início. |
| **Desfecho secundário** | Resultados ou eventos adicionais previstos. |
| **Dispensa de TCLE** | Autorização do CEP para não obter o TCLE quando isso for inviável ou arriscado (Res. 466, IV.8). |
| **Emenda** | Modificação de projeto aprovado, submetida para apreciação. |
| **Equipe de pesquisa** | Membros que atuam no estudo, sem acesso ao projeto na Plataforma. |
| **Folha de rosto** | Documento gerado pela Plataforma Brasil, assinado pelo pesquisador, pela instituição proponente e pelo patrocinador (se houver). |
| **Grupo-controle** | Participantes que não recebem a intervenção; devem ter acesso a ela se se mostrar eficaz. |
| **Impedimento ético** | Situação em que um membro do CEP deve se abster por envolvimento na pesquisa. |
| **Incapacidade** | Falta de capacidade civil para consentir; exige representante legal (TCLE do responsável e TALE). |
| **Indenização** | Reparação por dano decorrente da pesquisa (Res. 466 e Código Civil). Diferente de ressarcimento. |
| **Instituição participante** | Centro de estudo multicêntrico, com pesquisador responsável próprio. |
| **Instituição proponente** | Instituição de vínculo do pesquisador responsável, que apresenta a pesquisa e define o CEP que a analisa. |
| **Multicêntrico** | Protocolo único conduzido em vários centros, cada um com seu pesquisador responsável. |
| **Notificação** | Envio de documentos (relatórios, comunicações) sem alterar o projeto. |
| **Parecer consubstanciado** | Parecer formal do CEP/CONEP: aprovado, pendente, não aprovado ou retirado. |
| **Pendência** | Exigência de correção ou complementação. O pesquisador tem 30 dias para responder. |
| **Pendência documental** | Pendência emitida na checagem documental, antes da análise ética. |
| **Pesquisa envolvendo seres humanos** | Pesquisa que envolve o ser humano direta ou indiretamente, no todo ou em partes, incluindo o manejo de informações ou materiais. |
| **Pesquisador responsável (principal)** | Quem submete o projeto na Plataforma Brasil e responde pela pesquisa e pelos participantes. Em projeto acadêmico, o orientador. |
| **Projeto anterior** | Opção da Plataforma para pesquisas aprovadas antes de 15/01/2012. |
| **Protocolo de pesquisa** | Conjunto de documentos submetidos ao CEP: folha de rosto, projeto, termos e declarações. |
| **Recurso** | Pedido de reconsideração de parecer de não aprovação (ao CEP e depois à CONEP, 30 dias cada). |
| **Relator** | Membro do CEP que analisa o protocolo e emite o parecer de relatoria. |
| **Ressarcimento** | Compensação **exclusivamente de despesas** (transporte, alimentação) do participante e dos acompanhantes. Não é remuneração. |
| **Risco da pesquisa** | Possibilidade de dano às dimensões física, psíquica, moral, intelectual, social, cultural ou espiritual, em qualquer fase. |
| **RPP** | Representante dos Participantes de Pesquisa, membro do CEP indicado pelo controle social. |
| **TAI** | Termo de Autorização Institucional: autorização e declaração de infraestrutura do local de coleta. |
| **TALE** | Termo de Assentimento Livre e Esclarecido, para menores de 18 anos ou legalmente incapazes. |
| **TCLE** | Termo de Consentimento Livre e Esclarecido: convite escrito em linguagem acessível que informa e garante direitos. |
| **Testemunha imparcial** | Pessoa que acompanha o consentimento quando o participante não pode ler (cegueira, analfabetismo). |
| **Título principal / título público** | O principal pode conter informação confidencial; o público aparece em consultas após a aprovação. |
| **Via (vs. cópia)** | O participante tem direito a uma **via** original assinada (TCLE em papel). "Cópia" só se usa no TCLE online. |
| **Washout** | Período sem medicação, para eliminá-la do organismo antes da intervenção. |
